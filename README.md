# Youssef Ben Ghorbel — Portfolio

A modern, interactive portfolio built with React + Vite, designed around a Modernized Constructivist visual identity inspired by game UI and technical HUDs.

## Design

* Bold, asymmetrical layouts
* Geometric shapes and 45° elements
* High-contrast blue palette
* Sharp rectangular components
* Manrope typography
* Minimal shadows and gradients
* Playful, technical visual language

## Tech

* React
* Vite
* React Router
* CSS
* GitHub Pages
* Cloudflare

## Features

* Responsive design
* Project showcase and detail pages
* Custom 404 page
* Smooth page transitions
* Image reveal and scroll animations
* Interactive hover states
* Loading animations
* Reduced-motion support

## Structure

```
src/
├── assets/
├── components/
├── pages/
├── App.jsx
├── main.jsx
└── index.css
```

## Development

```
npm install
npm run dev
```

## Build for production:

```
npm run build
```
